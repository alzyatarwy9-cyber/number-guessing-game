# 🎮 Number Guessing Game (لعبة تخمين الأرقام)

لعبة بسيطة مكتوبة بلغة بايثون (Python)، تتيح للمستخدم تخمين رقم مخفي يختاره الكمبيوتر عشوائياً بين 1 و 50 خلال 5 محاولات فقط.

## 🛠️ التقنيات المستخدمة
* Python 3
* مكتبة العشوائية (`random module`)

## 🚀 طريقة التشغيل
1. تأكدي من تثبيت لغة بايثون على جهازك.
2. قومي بتنزيل ملف `guess_game.py` أو نسخه.
3. تشغيل الكود عبر سطر الأوامر أو بيئة التطوير الخاصة بك:
   ```bash
   python guess_game.py
